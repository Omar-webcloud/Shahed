# Doctor Portfolio Website

A modern, responsive, and performance-optimized personal portfolio website for Dr. Shahed Chowdhury (MBBS, CMCH).  
The project presents a professional medical identity with a focus on clinical expertise, education, certifications, and patient-centered care.

## Live Demo

https://dr-shahed.web.app

---

## Project Overview

This is a single-page medical portfolio website designed to establish a strong and credible digital presence for a medical practitioner.

The website emphasizes:

- Professional medical branding
- Clean and structured UI
- SEO optimization for discoverability
- Mobile-first responsive layout
- Smooth interactive user experience

---

## Key Features


### UI/UX Design
- TailwindCSS-based responsive interface
- Dark and light mode with persistent state
- Animated SVG splash screen
- Typewriter text animation in hero section
- Floating UI elements for visual enhancement

### Structured Content Sections
- Hero introduction
- About section (clinical values and background)
- Education and training timeline
- Medical services overview
- Contact and social media links

### Performance & Optimization
- Vanilla JavaScript for lightweight interactivity
- CDN-based dependencies for fast load time
- Optimized assets and minimal overhead
- Scroll-aware navbar behavior

### SEO & Social Integration
- Open Graph meta tags for social sharing
- Twitter Card support
- JSON-LD structured data using Physician schema
- Canonical URL configuration
- Keyword-optimized metadata

---

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- JavaScript (Vanilla)
- Anime.js (ESM module)
- Lucide Icons
- Font Awesome
- Google Fonts (Fraunces, Bricolage Grotesque)
